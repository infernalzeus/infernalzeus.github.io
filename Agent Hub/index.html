What it does

Turns a personal toolchain into one place.

Agent Hub does not replace each application. It starts, supervises and securely reaches the tools that already do their jobs.

01

Missions

Creates isolated git worktrees for autonomous coding work, runs single, team, parallel or orchestrated pipelines, then presents one reviewable diff to apply or discard.

02

TALK

Provides local speech recognition, rule-first commands and neural text-to-speech for navigating the Hub, checking work and issuing bounded PC actions.

03

PC control

Uses an explicit control gate: direct routines handle safe browser and app launches, while Windows MCP is reserved for UI-state and multi-step agent work.

04

Project graph

Builds a live D3 map from local project folders and git state, so the portfolio becomes an operational view rather than a static project list.

05

Tool launcher

Starts configured web tools only when needed, proxies them through one address and stops them after inactivity instead of keeping every process alive.

06

Media & files

Fronts a file browser, video clipping workflow and YouTube upload/download utilities, with setup diagnostics for missing optional pieces.

How it is connected

Private by design, not a public cloud dashboard.

Private mesh only

Tailscale is the road.

The Hub stays on the owner’s Windows PC. Tailscale provides the encrypted route from approved devices; it does not expose every underlying tool to the internet or wake a stopped computer.

1
Open Agent HubThe Windows launcher starts the Hub hidden and opens it in an app-style browser window.
2
Reach one secure addressTailscale Serve can provide a HTTPS tailnet address for the owner’s phone, tablet and desktop.
3
Activate only the needed toolEach configured app stays on localhost behind the Hub’s proxy and is launched on demand.
Everyday setup

One Windows installer, then private access from every device.

The first public release should make the owner’s PC the host, Tailscale the secure connection between devices, and a saved mobile shortcut the everyday entry point.

What a new user would do

1
Install Agent Hub on the Windows PCA signed installer adds the Hub, desktop and Start-menu shortcuts, then opens a plain-language first-run wizard.
2
Install Tailscale wherever they use HubOn the PC, phone, tablet and any extra computer, install Tailscale and sign in to the same tailnet or accept the owner’s invite.
3
Save Hub to the phone home screenOpen the private HTTPS Hub address once, then use “Add to Home Screen” on iPhone or “Install app” in Android Chrome. Its icon opens Hub like an app.

What the Windows package will create

  • A signed .exe installer containing Agent Hub’s runtime, so Python is not a separate prerequisite.
  • A first-run wizard for the Tailscale connection, local project folders and optional integrations such as OpenCode or YouTube.
  • A private HTTPS address through Tailscale Serve after the user signs in and enables it.
  • Clear status when the host PC is sleeping, off or Agent Hub is not running, because a phone shortcut cannot wake it.

Platform scope

  • Windows: first packaged release, including the desktop-control features already built for Windows.
  • macOS: a future signed .dmg/.app after the Windows lifecycle and automation code is made cross-platform; it cannot be a repackaging of today’s files.
  • Linux: source release remains appropriate for technical users; a consumer installer is not part of the first release.
